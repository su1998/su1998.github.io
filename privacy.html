개인정보처리방침 · Privacy Policy

시행일 · Effective date: 2026-09-30

1. 접근하는 Google 데이터

bnh-rclone 은 Google Drive 의 drive.file 권한만 요청합니다. 이 앱이 직접 만든 파일과 폴더만 읽고 쓸 수 있으며, 사용자의 다른 Drive 파일, 메일, 연락처 등은 보지 않습니다.

2. 이용 목적

앱 소유자 본인의 작업 파일을 소유자 본인의 Google Drive 로 올리고 내려받는 데에만 씁니다.

3. 저장

로그인 토큰은 소유자의 컴퓨터와 소유자가 직접 설정한 실행 환경에만 저장됩니다. 파일 내용은 소유자의 Google Drive 에만 저장됩니다.

4. 공유·판매

Google 사용자 데이터를 제3자에게 제공하거나 판매하지 않으며, 광고에 쓰지 않습니다. bnh-rclone 이 Google API 로 받은 정보의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 해제와 삭제

Google 계정의 타사 앱 액세스 화면에서 언제든 권한을 해제할 수 있습니다. Drive 에 올라간 파일은 소유자가 Drive 에서 직접 지울 수 있습니다.

6. 문의

GitHub @su1998

English

Data accessed. bnh-rclone requests only the Google Drive drive.file scope. It can read and write only the files and folders it created itself. It does not access the user's other Drive files, email, contacts or any other Google data.

Purpose. Uploading and downloading the owner's own work files to and from the owner's own Google Drive.

Storage. Sign-in tokens are stored only on the owner's computer and in execution environments the owner configures. File contents are stored only in the owner's Google Drive.

Sharing. Google user data is never shared with or sold to third parties and is not used for advertising. bnh-rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking and deleting. Access can be revoked at any time on the Google Account third-party access page. Uploaded files can be deleted by the owner in Google Drive.
