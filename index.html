bnh-rclone

bnh-rclone 은 GitHub 사용자 su1998 이 자기 컴퓨터의 작업 파일을 자기 Google Drive 로 백업하고 동기화하려고 만든 개인용 도구입니다. 오픈소스 프로그램 rclone 으로 동작하며, 다른 사람에게 제공하는 서비스가 아닙니다.

bnh-rclone is a personal tool made by GitHub user su1998 to back up and sync the owner's own work files to the owner's own Google Drive. It runs on the open-source program rclone and is not offered as a service to anyone else.
